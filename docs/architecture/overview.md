# H0RII ONE Architecture

Naming:

- **H0RII ONE** = native iOS assistant app.
- **H0RII CORE** = VPS backend/control plane.
- **H0RII PWA** = installable web client, future camera node/dashboard.
- **H0RII HOME** = future smart-home layer.

Milestone 0 builds CORE foundation only, while keeping repo structure ready for iOS/PWA/device modules.
